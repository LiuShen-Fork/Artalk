# 侧边栏

侧边栏同时充当 **通知中心** + **控制中心** 的功能，当用户填写评论框的“**昵称**”和“**邮箱**”后，侧边栏入口按钮能在评论框右下角找到。

<img src="/images/sidebar/1.png" width="650">

## 通知中心

Artalk 拥有站内消息功能，在接收邮件通知的同时，也能在侧边栏查看消息。

在侧边栏可以查看与自己相关的评论，分类包括：提及、全部、我的、待审。

你能快速找到评论，并跳转到对应页面。

<img src="/images/sidebar/2.png" width="430">

当用户收到消息时，会显示红点标记。

<img src="/images/sidebar/3.png" width="350">

另外，你能在侧边栏快速回复对方的消息，无需切换到评论页面。

<img src="/images/sidebar/4.png" width="400">

## 控制中心

管理员账户侧边栏将自动从“通知中心”升级为“控制中心”。

管理员输入“昵称”和“邮箱”后，将弹出密码验证提示框：

<img src="/images/sidebar/5.png" width="600">

进入侧边栏，你可以对评论、页面、站点等内容进行管理操作。

<img src="/images/sidebar/6.png" width="800">

点击左上角的站点图标，你能在多个站点之间快速切换。

<img src="/images/sidebar/7.png" width="400">

登录管理员账户进入“控制中心”的设置界面，可修改 [配置](../backend/config.md) 和 [界面](./config.md)，无需编辑复杂的配置文件。

## 控制台的两个视图（本仓库新增）

本仓库把侧边栏重写为 React 控制台，并把「管理」和「个人」拆成两个视图，同一个账号可以在侧栏顶部（宽屏）或底部导航（窄屏）随时切换：

- **管理视图**：数据总览、评论管理、内容审核、页面管理、用户管理、站点管理、安全防护、系统设置、站点配置、数据迁移，仅管理员可见；
- **个人视图**：我的概览、我的评论、我的账户，任何登录用户都可以使用。

访问范围同时受视图与角色限制：普通用户无法通过 URL 进入管理页面，管理员在个人视图下打开管理地址会被跳回个人视图。「我的账户」只出现在个人视图里，管理员从右下角的账户菜单点「我的账户」时会自动切到个人视图。

「我的概览」把当前账号的发言按天汇总成热力图（默认 182 天），并给出总数、近 30 天、获赞数与连续活跃天数，下方列出最近发言，数据来自 `GET /api/v2/user/activity`。

## 界面自适应

- 宽度 ≥ 1280px：完整侧栏，分组标题与文字标签齐全；
- 768–1280px：折叠为 76px 图标栏，图标居中，悬停显示提示；
- 更窄（评论组件 iframe 默认 430px）：底部标签栏 +「更多」抽屉。

控制台本身也适配键盘与触屏：所有弹窗、抽屉、下拉菜单都来自组件库，焦点顺序与遮罩行为与系统一致。

## 站点配置：名称、图标、介绍与自定义代码（本仓库新增）

管理员在「站点配置」页面可以改名控制台、换图标、写一句介绍，并注入自定义样式和脚本；保存后立即生效，无需重启服务。内容保存在配置文件的 `console` 段（这一段只在「站点配置」页面出现，「系统设置」里不再重复列出）：

```yaml
console:
  name: Artalk # 名称，留空则用默认值，显示在侧栏、页面标题和登录页
  icon: '' # 图标，http(s) 链接或站内路径，留空则用名称首字母
  description: '' # 一两句话介绍，显示在登录页，留空则用内置文案
  css: '' # 追加到控制台的样式表
  js: '' # 在控制台执行的脚本（请只填入自己信任的代码）
```

- 名称、图标与介绍会同步到侧栏、窄屏顶栏、浏览器标题和登录页，留空即回到内置外观；
- `console.css` 以 `<style id="artk-custom-css">` 注入 `<head>`，覆盖主题变量即可整体换色，例如 `:root { --accent: oklch(0.62 0.2 20); --control-radius: 4px; }`；
- `console.js` 以 `<script id="artk-custom-js">` 每次加载重新执行；
- 单段上限 256 KB，只作用于本控制台，不影响前台评论组件；
- 也可以直接编辑配置文件，或使用环境变量 `ATK_CONSOLE_NAME` / `ATK_CONSOLE_ICON` / `ATK_CONSOLE_DESCRIPTION` / `ATK_CONSOLE_CSS` / `ATK_CONSOLE_JS`（由环境变量接管时代码只读）；
- 接口：`GET /api/v2/sidebar/console`（公开，前端启动时读取），`PUT /api/v2/sidebar/console`（仅管理员）。
