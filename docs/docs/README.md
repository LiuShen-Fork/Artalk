# Artalk Fork Documentation

[![Netlify Status](https://api.netlify.com/api/v1/badges/6580cce0-4b27-465e-8d73-1e6a832942e9/deploy-status)](https://app.netlify.com/sites/artalk/deploys)

Documentation for the [LiuShen-Fork/Artalk](https://github.com/LiuShen-Fork/Artalk) repository. It is based on the upstream [ArtalkJS/Artalk](https://github.com/ArtalkJS/Artalk) documentation and includes fork-specific configuration and feature notes where applicable. For upstream-only behavior, use the official documentation at [artalk.js.org](https://artalk.js.org).

## Build

```bash
pnpm dev:docs
pnpm build:docs
```

## Deploy

The documentation is automatically deployed from the `master` branch through [Netlify](https://www.netlify.com/).
